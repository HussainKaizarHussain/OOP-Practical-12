# OOP-Practical-12: Mini Project: Library Management System

## Purpose & Aim
- **Aim**: To apply concepts from the course in a small, complete application that solves a real-world problem.
- **Question**: Build a console-based application that combines OOP, STL, exception handling, file I/O and Git-based collaboration.

---

## What to Do
- Manage books with book ID, title, author and availability.
- Add, search, and list books, and issue or return a book.
- Store book data in a CSV file (`books.csv`) and load it automatically when the program starts.
- Use STL containers (`std::vector`) to maintain records and handle unknown IDs or unavailable books safely using custom exceptions.
- Use Git commits during development and push the final version to GitHub with a complete README and setup instructions.
